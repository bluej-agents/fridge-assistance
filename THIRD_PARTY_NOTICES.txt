Scope
-----
This source distribution contains application source, static assets, example
data, tests and dependency requirement files. It does not bundle Python,
Node.js, a browser, dependency source trees, wheels, virtual environments or
native shared libraries. pip installs third-party packages separately.

The inventory below describes the versions recorded in requirements-lock.txt
(Windows / Python 3.12), including development and transitive packages.
Other resolution choices may install different versions. License identifiers
were checked against installed distribution metadata and included license
files; identifiers alone do not replace their full terms. The package and
source links provide upstream provenance. Keep the applicable LICENSE and
NOTICE files when redistributing dependency code or binaries.
